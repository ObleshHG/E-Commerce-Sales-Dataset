# E-Commerce Sales Analysis Using Microsoft Excel

## Project Overview

This project analyses e-commerce sales data using Microsoft Excel to understand sales performance, product trends, and business KPIs.

## Objectives

* Clean and organise sales data.
* Analyse total sales, profit, and quantity sold.
* Identify top-performing products and categories.
* Track monthly sales trends.
* Build an interactive dashboard using PivotTables, charts, and slicers.

## Tools Used

* Microsoft Excel
* PivotTables
* Excel formulas
* Charts and slicers
* KPI reporting

## Project Workflow

1. Import and inspect the dataset.
2. Clean missing values and duplicates.
3. Calculate important KPIs.
4. Create PivotTables and charts.
5. Develop a dashboard.
6. Summarise findings and recommendations.

## Dataset

File: `E-commerce_sales_dataset.xlsx`

## Key Performance Indicators

* Total Sales
* Total Profit
* Total Quantity Sold
* Average Order Value
